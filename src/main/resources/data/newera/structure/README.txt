# Thư mục lưu trữ Structure Block NBT của Mod NewEra
# =========================================================
#
# Để thay đổi Bệ Đá Trung Tâm (Exit Portal / Podium):
# 1. Trong game, xây dựng bệ tế đàn / đài sen theo ý thích.
# 2. Dùng Structure Block (chế độ LƯU / SAVE), đặt tên công trình là:
#    - newera:end_podium (cho trạng thái khi rồng còn sống)
#    - newera:end_podium_active (cho trạng thái khi rồng đã bị đánh bại, có cổng mở)
# 3. Bấm LƯU (SAVE). File .nbt sẽ được tạo trong:
#    .minecraft/saves/<Tên_Thế_Giới>/generated/newera/structures/end_podium.nbt
# 4. Copy file end_podium.nbt đó và dán vào chính thư mục này:
#    src/main/resources/data/newera/structure/end_podium.nbt
#
# Khi vào game hoặc hồi sinh rồng, game sẽ tự động nạp công trình mới này thay cho cái bồn Bedrock cũ!
